## Bottom line

- No source found that is BOTH licence-compatible AND a registerable whole-limb / pelvic nerve geometry set. The only open geometry that is licence-compatible is already merged (Z-Anatomy, HRA); the richest unmerged geometry (Steer / Holliday human hand, nerves included) is non-commercial.
- Z-Anatomy is the ceiling for MERGE-quality geometry: its release has no phrenic, perineal / pudendal branches, inferior gluteal, recurrent laryngeal, etc. (only empty group names). HRA and BodyParts3D carry no peripheral nerve at all (optic nerve + spinal cord only).
- Gaps tier 1 (pudendal branches, levator ani nerve, sacral roots, inferior gluteal, hypogastric / pelvic splanchnic, dorsal-ramus medial branches, phrenic) can only be closed by RULE-BASED construction (section "Integration plan") from `data/nerves/*.json` (303 entities, Gray's-derived targets) plus the vessels / muscles / bones already on the pages, with the error badge. No download is needed for that.
- Open text / graph resources worth merging as FACTS (names, routes, no geometry): SPARC SCKAN (CC BY 4.0). Open micro-anatomy: human cervical vagus fascicles (CC BY 4.0, not registerable).

## Integration plan (nothing implemented)

No MERGE-quality source closes a significant tier-1 gap, so the proposal is a rule-based layer, CC BY-SA compatible because every input is already on the pages or public-domain text:

1. Gap set (tier 1): pudendal branches (inferior rectal, perineal, dorsal n. of clitoris / penis), n. to levator ani / coccygeus, S1-S4 ventral rami + lumbosacral trunk, inferior gluteal n., n. to obturator internus, hypogastric / pelvic splanchnic nn., cervical / thoracic / lumbar dorsal-ramus medial branches, phrenic n.
2. Method: polyline centreline per nerve from the `data/nerves/*.json` course text (Gray's), anchored to named landmarks already on the pages, then a tube of the calibre level from `calibre.json` (levels: trunk >= 4 mm, branch >= 2, small >= 1, fine < 1). Landmarks present on the Z pages: internal pudendal artery / vein L+R, inferior and superior gluteal vessels, obturator internus, levator ani + pubo- / iliococcygeus, coccygeus, piriformis, pudendal trunk, sciatic, PFCN, bones (sacrum foramina, ischium, vertebrae); HRA blood vasculature adds internal pudendal vein on the female pages. Example: pudendal branches follow the internal pudendal vessels on the medial obturator internus wall, then split at the perineal membrane; levator ani nerve runs on the pelvic surface of the muscle from S3-S5 roots; dorsal-ramus medial branches sit at the base of each facet joint.
3. Expected error: not measurable without a reference. Floor = existing bone registration residual of each page (Q233 pelvis transform for HRA objects; Q168 per-bone fits on Combined pages; Q173 photo registration on the male imaging page) plus the anatomical variability of the course (to be sourced from the literature in item 20 / 21 before shipping). Badge text: "Rule-based: course from Gray's description, anchored to <landmarks> on this body; not measured; error bound = <registration residual> + <literature variability>", `source_class: rule_based` as already defined in `parts_data.json`.
4. Imaging pages: only where a measured structure can anchor it; never presented as measured.
5. Facts layer: add SCKAN names / parent links as optional CC BY text to the registry (attribution: SPARC / SAWG, Zenodo 18840513).
6. If the owner obtains a CC BY / BY-SA release of the Steer hand model (item 6), it would close the hand digital / palmar branch detail on the hand; registration by metacarpal and carpal landmarks, side to be fixed first; badge "transferred from another donor".
